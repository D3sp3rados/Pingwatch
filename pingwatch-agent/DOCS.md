# PingWacht Agent

1. Im PingWacht-Dashboard unter **Einstellungen → Standorte** einen Standort anlegen und **agent.json** herunterladen.
2. Den Wert hinter `"token"` aus der agent.json hier unter **Konfiguration → token** einfügen und speichern.
3. Add-on starten. Im Dashboard steht der Standort nach wenigen Sekunden auf „verbunden“.

Das Add-on lädt bei jedem Start die aktuelle Agent-Version vom PingWacht-Server.
